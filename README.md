# Cloud GRC + NIST Cybersecurity Assessment

## Overview

I completed a basic security assessment of my personal AWS environment using the NIST Cybersecurity Framework (CSF) 2.0.

The goal of this project was to review my cloud environment, identify security strengths and weaknesses, and recommend improvements based on industry best practices.

## Objectives

- Learn the NIST Cybersecurity Framework (CSF) 2.0
- Review the security posture of an AWS account
- Identify security gaps
- Document findings
- Recommend security improvements

## Environment

- AWS Free Tier Account
- AWS IAM
- AWS CloudTrail
- IAM Access Analyzer
- GitHub
